## ✨ 功能特色

### 🚀 核心功能

| 功能 | 說明 |
|------|------|
| **硬體加速** | 使用 VideoToolbox 硬體加速，轉檔速度提升 10-20 倍 |
| **品質百分比控制** | 品質 = 原始位元率的百分比（100% = 原始品質，50% = 檔案減半） |
| **目標大小壓縮** | 直接設定目標檔案大小（例如：壓縮到 100 MB 以下） |
| **解析度調整** | 自訂輸出寬度/高度，等比例縮放 |
| **音訊選項** | 保持原始音訊 / 壓縮音訊 / 靜音 |
| **批次處理** | 支援同時處理多個檔案 |
| **即時進度** | 顯示已用時間、預估剩餘時間、轉檔速度 |
| **再轉功能** | 可用不同設定重複轉換同一檔案 |

### 📁 支援格式

| 類型 | 支援格式 |
|------|----------|
| **輸入格式** | MOV, MP4, MPG/MPEG, WMV, WebM, AVI, MKV, FLV, M4V, 3GP |
| **輸出格式** | MP4 (H.264/H.265), WebM (VP9) |

### 🎛️ 編碼器選項

| 編碼器 | 說明 | 速度 |
|--------|------|------|
| **H.265 硬體加速** ⚡ | 最新壓縮標準 + VideoToolbox 加速 | 🚀 最快 |
| **H.264 硬體加速** ⚡ | 相容性最佳 + VideoToolbox 加速 | 🚀 最快 |
| **H.265 軟體** | 純 CPU 編碼，壓縮效率最高 | 🐢 慢 |
| **H.264 軟體** | 純 CPU 編碼，相容性最佳 | 🐢 慢 |
| **VP9** | 網頁影片專用 | 🐌 非常慢 |

## 📥 安裝方式

### 方法一：下載 DMG 安裝（推薦）

1. 下載 `Video Compressor-1.0.0-arm64.dmg`
2. 雙擊開啟 DMG 檔案
3. 將 **Video Compressor** 拖曳到 **Applications** 資料夾
4. 完成！

> ⚠️ **首次開啟注意**：因為此應用程式未經 Apple 簽署，首次開啟時：
> 1. 在 Applications 中找到 Video Compressor
> 2. **右鍵點擊** → 選擇 **打開**
> 3. 在彈出的對話框中選擇 **打開**

### 方法二：從原始碼安裝（開發者）

```bash
# 複製專案
git clone https://github.com/miku4ocean/mac-video-transfer.git
cd mac-video-transfer

# 安裝依賴
npm install

# 啟動開發版
npm run dev

# 打包成 DMG
npm run build
```

## 🔧 功能詳解

### 1️⃣ 壓縮品質（相對原始位元率）

品質滑桿控制輸出的位元率百分比：

| 設定 | 意義 | 預估檔案大小 |
|------|------|--------------|
| **100%** | 保持原始位元率 | ≈ 原始大小 |
| **75%** | 原始的 75% | ≈ 原始的 75% |
| **50%** | 原始的 50% | ≈ 原始的 50% |
| **25%** | 原始的 25% | ≈ 原始的 25% |

> 💡 **注意**：H.265 編碼在相同位元率下比 H.264 小約 15-30%

### 2️⃣ 快速預設

| 預設 | 品質 | 適用場景 |
|------|------|----------|
| ✨ **高畫質 (75%)** | 75% | 需要高畫質但想縮小一些 |
| ⚖️ **平衡 (50%)** | 50% | 一般用途（推薦） |
| 📦 **小檔案 (25%)** | 25% | 需要最小檔案 |

### 3️⃣ 音訊設定

| 選項 | 說明 | 建議使用場景 |
|------|------|--------------|
| **保持原始音訊** | 不重新編碼音訊 | 需要最佳音質 |
| **壓縮音訊 (128kbps)** | 重新編碼為 AAC 128kbps | 檔案更小 |
| **靜音（無音訊）** | 移除音訊軌道 | GIF 替代、字幕影片 |

### 4️⃣ 調整影像尺寸

勾選後可設定目標寬度/高度：

- 只設定**寬度**：高度自動等比例計算
- 只設定**高度**：寬度自動等比例計算
- 設定**兩者**：以較小的比例為準，保持比例

例如：3018×1790 的影片設定寬度 1024 → 輸出 1024×607

### 5️⃣ 壓縮至限定大小以下

啟用此功能可直接指定目標檔案大小：

1. 勾選「壓縮至限定大小以下」
2. 輸入目標大小（例如：100 MB）
3. 系統會自動計算需要的位元率
4. 品質滑桿會被禁用（由系統自動計算）

> ⚠️ **重要**：每個檔案下方會顯示「限定大小模式最小」值。
> 如果目標設定低於此值，音訊可能會被自動壓縮或靜音。

### 6️⃣ 再轉功能

在結果列表中點擊「🔄 再轉」按鈕：

- 自動將原始檔案加入待處理列表
- 可調整不同設定後重新轉檔
- 無需重複到資料夾選擇檔案

## ❓ 常見問題

### Q1：轉檔速度很慢怎麼辦？

**A**：請確認使用**硬體加速**編碼器：
- ✅ **H.265 硬體加速 ⚡** - 推薦
- ✅ **H.264 硬體加速 ⚡** - 推薦
- ❌ 避免使用 VP9（非常慢）

### Q2：壓縮後檔案比原來還大？

**A**：這不應該發生了！新版使用位元率控制：
- 品質 100% = 保持原始位元率（大致相同大小）
- 品質 50% = 檔案減半
- 如果仍有問題，請降低品質百分比

### Q3：目標大小設定後，輸出檔案還是超過？

**A**：這是正常情況。系統會盡可能接近目標，但：
- 實際大小可能有 ±10% 的誤差
- 如果差異很大，請檢查音訊設定

### Q4：轉檔後畫質明顯下降？

**A**：嘗試以下方法：
1. 提高品質百分比（例如 75% 或更高）
2. 不要過度縮小解析度
3. 使用 H.265 而非 H.264（同位元率下更高品質）

### Q5：應用程式無法開啟？

**A**：macOS 安全限制。請：
1. 右鍵點擊應用程式
2. 選擇「打開」
3. 在對話框中選擇「打開」

### Q6：如何處理超大檔案（10GB+）？

**A**：建議：
1. 使用 **H.265 硬體加速**
2. 設定適當的**目標大小**
3. 如果需要，可以**縮小解析度**（例如 4K → 1080p）
4. 耐心等待，大檔案需要較長時間
